# Aether Dash — portfolio brief

Purpose: a compact, honest first Godot portfolio piece for the application, distinct from the employer's checkpoint test. User approved an airborne-dash course and delegated remaining decisions.

Deliverable: Windows build, Godot source, gameplay clip, and README with credits and AI assistance disclosure. No public upload without review.

Design: one floating-island course. WASD moves, Space jumps (double jump), Shift dashes in movement direction. Landing or passing a fresh energy ring refills one dash. All rings are required to open the finish. Falling restarts the run; R restarts immediately. A timer starts on first movement; finish freezes the timer and offers replay. Escape pauses. No checkpoints, combat, upgrades, accounts, or online features.

Art: midnight-blue sky, cyan energy rings, coral route markers, Kenney character and sounds. High contrast HUD, clear next-ring guidance, reduced-motion toggle. Tune exposed movement parameters with actual physics tests, then inspect rendered gameplay.

Safety: source Kenney project on D remains unchanged; work only in this independent copy. Engine 4.7.2. Keep Kenney MIT and CC0 attribution. Distinguish original assets/controller from new work.

Acceptance: reachable course via real input replay; no runtime errors; empty dash cannot repeat; fresh rings restore dash once; restart clears progress, velocity, timer; finishing requires all rings; pause freezes timer; Windows export launches independently.
